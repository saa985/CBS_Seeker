CBS_Seeker
Travelers at the City Bus Stand in Mysore often face stress trying to locate the correct platform or bus number for their destination. CBS_Seeker simplifies this by providing a quick, searchable interface that maps locations to specific bus numbers and platform details based on local transit data.

🚀 About the Project
Travelers at the City Bus Stand often face stress trying to locate the correct platform or bus number for their destination. CBS_Seeker simplifies this by providing a quick, searchable interface that maps locations to specific bus numbers and platform details based on local transit data.

🛠 Features
Instant Search: An autocomplete-enabled search bar to quickly find locations.
Efficient Data Mapping: Instantly retrieves Bus Numbers and Platform Numbers for a selected location.
Responsive UI: Built with Bootstrap and jQuery for a fast, mobile-friendly experience.
Lightweight: All logic, styling, and data are contained within a single file for maximum portability and speed.

💻 Tech Stack
HTML5
CSS3 (Bootstrap 5)
JavaScript (jQuery)

⚠️ Disclaimer
This is an informational tool. While data is collected from official CBS boards, local events or temporary changes may affect bus schedules. Please verify the details with the bus conductor before boarding.
